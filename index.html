Important: antivirus software can sometimes mistakenly block automated installers. If you are sure the file comes from a trusted source, do this:

  1. Open Windows Defender Setting.
  2. Go to Virus & threat protection.
  3. Temporarily pause Real-time protection.
  4. Run the installer and complete the setup.
  5. Turn protection back on immediately — do not leave your antivirus disabled.
